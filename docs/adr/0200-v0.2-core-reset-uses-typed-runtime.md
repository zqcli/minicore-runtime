# ADR 0200: v0.2 Core Reset Uses a Typed Runtime

状态：Accepted

> Historical v0.2 record. P4-B physically deletes this Runtime/configuration and
> multi-session manager implementation; current ownership is SessionRuntime.

日期：2026-08-20

## Context

The current crate needs one source-accurate public boundary for a durable coding session. The previous repository surface combined transport payloads, platform entities, lifecycle routing, and multiple ownership models. Keeping aliases for that surface would make the v0.2 contract ambiguous and would preserve owners that are no longer compiled.

## Decision

The historical v0.2 boundary was `Runtime` plus checked configuration and canonical `model`, `tools`, `workspace`, and `session` modules. In the current v0.3 slice, the top-level runtime module is deleted. The public boundary is the host-neutral Port set plus one non-Clone SessionRuntime owner for each created or loaded Session; workspace remains private migration implementation.

One loaded session has one actor, one bounded mailbox, one conversation log, one workspace, and one active turn at most. The turn runner and prompt builder remain private. No compatibility alias, transport adapter, or alternate source graph is compiled by the core.

## Consequences

Historically Hosts translated commands into typed Runtime calls. Current Hosts acquire SessionLog adapters and manage multiple SessionRuntime owners externally. Provider and tool installation remain explicit Host responsibilities.
