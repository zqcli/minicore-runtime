# ADR 0200: v0.2 Core Reset Uses a Typed Runtime

状态：Accepted

> Transitional v0.2 record. P3-B removes this Runtime/configuration facade from
> the public crate surface; the implementation remains only for later migration.

日期：2026-08-20

## Context

The current crate needs one source-accurate public boundary for a durable coding session. The previous repository surface combined transport payloads, platform entities, lifecycle routing, and multiple ownership models. Keeping aliases for that surface would make the v0.2 contract ambiguous and would preserve owners that are no longer compiled.

## Decision

The historical v0.2 boundary was `Runtime` plus checked configuration and canonical `model`, `tools`, `workspace`, and `session` modules. In the current v0.3 slice, `runtime` and `workspace` are private migration modules; the public boundary is the host-neutral Tool/ToolSet seam plus typed Ports. `Runtime::open(RuntimeConfig, tokio::runtime::Handle)` remains transitional implementation detail.

One loaded session has one actor, one bounded mailbox, one conversation log, one workspace, and one active turn at most. The turn runner and prompt builder remain private. No compatibility alias, transport adapter, or alternate source graph is compiled by the core.

## Consequences

Hosts must translate their own commands and data into typed Runtime calls. Provider and tool installation are explicit host responsibilities. The public contract is smaller, but ownership and failure authority are inspectable from the canonical source graph.
